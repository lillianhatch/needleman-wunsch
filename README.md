# Needleman-Wunsch Algorithm

A basic Python implementation of the Needleman-Wunsch algorithm for global sequence alignment. I originally wrote this from scratch as a fun extra-credit project to practice dynamic programming and matrix scoring.

This repository contains a single Jupyter Notebook (`For Fun Needleman-Wunsch.ipynb`) that executes the standard matrix initialization, scoring, and traceback steps to output the optimal alignment path for two sequences.
